# LectureLite

**文件 + 音频 + 操作时间轴** —— 不用录屏的轻量讲解工具。

把 `.md` / `.pdf` 文档、你的讲解音频，以及讲解过程中的操作（滚动、选词、点击）
打包成一个 `lecture.zip`；同事打开分享链接即可自动播放还原，无需安装任何软件。

## 功能

- 🎙 **录制**：加载 `.md` / `.pdf`（或选择含 `images/` 的 md 项目文件夹），配合麦克风录制讲解；
  自动记录页面滚动位置、文字选中、鼠标点击；支持**多文件工作区**——像浏览器 tab 一样切换/追加文件，停止后导出 `lecture.zip`
- ✨ **AI 讲解稿 + 一键生成**：由 LLM 逐句生成带锚点的讲解稿，文档里的问题、步骤、方法**逐个展开讲全**，不跳过重要内容；
  模型同时规划每句的视觉操作（高亮 / 下划线 / 删除线 / 批注，批注只留给最重要的知识点），
  标记**重难点**（🔥，讲稿里带“注意，这里是重点”之类的口语提示），
  并在提问、关键结论后自动插入**思考停顿**（⏸），章节切换处带自然过渡句（“好，现在我们来看正文”）；
  讲稿可在右侧面板编辑 / 重新生成
- 🎧 **一键录音像**：点「录制演讲」直接调用 edge-tts 在线语音合成，按讲稿逐句合成（含停顿），
  无需实时播放/录音即可生成带语音与完整操作时间轴的讲解包；音色（晓晓 / 云希 / 云健 / 晓伊 / 云扬）与语速可选
  （需 `pip install edge-tts`，在线合成失败时自动回退为浏览器语音实时录制）
- 💬 **字幕**：播放 AI 生成的讲解包时，底部字幕条随讲稿逐句同步滚动；
  点「字幕」按钮开/关，⚙ 可调透明度（默认 72%）与字号（默认 16px），设置本地记忆
- ▶️ **播放**：加载 zip 后按音频时间轴自动滚动页面、还原光标与点击效果——光标在锚点之间沿随机弧线的
  “慢—快—慢”轨迹平滑滑动，模拟人手；录制中的多文件切换也会自动还原。支持拖动进度、0.75×–2× 变速，空格暂停/继续
- ✍️ **标注**：鼠标选中文字后自动出现浮动工具栏，也可右击呼出；主栏提供高亮、下划线、删除线和批注，问号与透明线性贴纸收纳在“更多”中。批注以波浪线标记，悬停或点击后显示内容
- 🔗 **分享**：配合 `serve.py` 把 zip 上传到局域网服务，一键生成播放链接发给同事

## 快速开始

依赖仅 Python 标准库（edge-tts 为可选依赖，AI 一键语音生成需要）：

```bash
python serve.py            # 启动后自动打开浏览器，打印本机与局域网地址
pip install edge-tts       # 可选：「录制演讲」一键语音生成
```

## 使用说明

1. **录制**：切到「录制」→ 选择文件 / 文件夹 → 开始录制（允许麦克风）→ 边讲边滚动、选词、点击；可点工作区 `+` 添加更多文件并切换 → 停止后导出或分享
2. **标注**：拖选一段文字 → 在浮动提示中选择标注工具；点击任意已标注内容可删除该标注，按 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 可撤回最近一次新增或删除。批注内容通过波浪线悬停查看，其显隐过程也会进入录制时间轴
3. **AI 一键讲解**：「录制」模式下点「✨ 自动生成文稿」→ 右侧面板逐句生成讲解稿（🔥 重难点、⏸ 思考停顿均带标记，可编辑）→ 选音色/语速后点「录制演讲」，一键生成带语音的讲解包
4. **播放**：切到「播放」→ 选择 `lecture.zip` → 播放；底部「字幕」按钮开/关字幕，⚙ 调透明度与字号
5. **分享**：点「分享」生成局域网链接，同事打开即自动加载并播放

页面也暴露了统一调用入口 `window.lectureLiteAnnotations.add(annotation)`，后续 AI 讲解可传入 `type`、`fi`、`offsets`（Markdown）或 `coords`（PDF）来创建同样的时间轴标注。

## 产物结构

```
xxx.lecture.zip
├── 源文件（md / pdf / images/ … 多个文件）
├── audio.webm / audio.wav    # 浏览器录制为 webm，edge-tts 合成为 wav
└── lecture.json              # 时间轴：states + cursor + clicks + fileSwitches
                              #           + annotations + annotationPopups + script
```

`script` 是讲稿时间轴，每句一条：

```json
{ "text": "…", "anchor": "文档原文锚点", "t": 12500, "d": 3200,
  "op":  { "kind": "highlight", "target": "…" },   // 该句触发的视觉操作（可选）
  "pause": 1500,    // 句尾思考停顿（毫秒，可选）
  "key": true }     // 重难点句（可选）
```

`anchor` 是文档中逐字出现的原文片段，播放端靠它在页面里定位该句——用于自动滚动、
光标落点与标注创建，因此讲解包与源文档天然对齐。

## 环境要求

- 建议使用 Chrome（依赖 MediaRecorder / webkitdirectory）
- 页面需联网加载渲染库（markdown-it / pdf.js / jszip，走 CDN）
- edge-tts 在线合成需能访问微软 TTS 服务

## 项目结构

```
MDLecture/
├── lecture-lite.html    # 单页前端（录制 + 播放 + AI 讲解稿 + 字幕）
├── tools/               # 选区工具栏与六种独立标注工具
├── llm/                 # LLM 讲解稿生成（script_generator.py）+ edge-tts 语音合成（tts_generator.py）
├── serve.py             # 局域网 HTTP 服务 + /share 分享 + 讲解稿/语音生成接口
├── docs/screenshot.png  # 界面截图
└── shared/              # 运行时上传的分享文件（不入库）
```
